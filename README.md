# BANKOO — مرئيات التطبيق (نسخة مفاهيمية v0.1)

تتضمن هذه الحزمة ملفات PNG منظّمة للشخصية الرئيسية، تعبيراتها، الشخصيات المساعدة، صور بروفايل الأطفال، الأيقونات، منتجات المتجر، والمناطق التعليمية.

## سياسة الادخار
لا يستخدم التطبيق رمز الخنزير نهائيًا. رموز الادخار الموصى بها: خزنة زرقاء، صندوق ادخار، وعاء زجاجي للعملات، وهدف مالي.

## تنبيه للإنتاج
هذه مرئيات استكشافية أصلية من لوحات مفاهيم؛ بعضها يضم خلفيات أو أطراف بطاقات ويحتاج نسخة شفافة دقيقة قبل الإطلاق. لا تعتمد النصوص الصغيرة والأرقام المطبوعة داخل الصور كبيانات حقيقية. استخدم نصوص واجهة حقيقية قابلة للترجمة والوصول.

الأقسام: `branding`, `mascot`, `avatars`, `characters`, `icons`, `finance`, `documents`, `products`, `world`.

## أيقونات Vector SVG
تمت إضافة أيقونات SVG قابلة للتكبير وملفات PNG بجودة 256×256. جميع رموز الادخار صناديق أو خزائن أو أوعية للعملات، دون أي رمز للخنزير.
