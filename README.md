# BANKOO — بنكوو

**«بنكوو... تعلّم، اربح، وفّر، واصرف بذكاء!»**

منصة SaaS تعليمية جزائرية للثقافة المالية والدفع الإلكتروني للأطفال (6–16 سنة)، عبر اقتصاد صفّي افتراضي آمن. العملة **بانكوز** افتراضية بالكامل وليست مالًا حقيقيًا.

## محتوى المستودع

| المسار | المحتوى | الحالة |

| [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) | حزمة المرحلة 1: الفهم، نقاط القوة والضعف، المعمارية، المسارات، Sitemap، نظام التصميم، المخطط، محرك الاقتصاد، المنهج، Backlog، MVP، معايير القبول | ✅ |

## التشغيل

```bash
# اختبارات محرك الاقتصاد (Node ≥ 22.18، بلا تبعيات)
cd packages/economy && npm test

# الشريحة الرأسية
cd apps/web-slice && python3 -m http.server 8080   # ثم افتح http://localhost:8080
```

## قواعد ثابتة

- الرصيد يتغيّر فقط بمعاملات معتمدة على الخادم؛ لا رصيد سالب؛ لا حذف للتاريخ المالي.
- لا بيانات مصرفية حقيقية، ولا مشتريات بمال حقيقي للأطفال، ولا روابط خارجية في محاكاة الاحتيال.
- لا رمز خنزير للادخار: خزنة زرقاء أو وعاء عملات.
- أقل قدر من البيانات: لقب الطفل وعمره فقط، بلا بريد ولا صورة حقيقية.

## الخطوة التالية

NestJS API (Auth/RBAC/Tenant Guard + Economy على PostgreSQL)، ثم نقل الشريحة إلى Next.js وربطها بالـ API. التفاصيل في القسم 10 من وثيقة المعمارية.
